# kynfra v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Costruire kynfra, plugin Claude Code e Codex che genera infrastruttura Terraform su AWS (7 pattern) protetta da guardrail che l'agente non può aggirare.

**Architecture:** Stessa architettura di kyfes (`/Users/vincenzo/Documents/Developer/kyfes`): motore di regole in Python standard library usato da hook (pre_write, post_edit, bash_guard, stop_gate) e da `arch_check`; installer idempotente; skill e agenti. In più: parser HCL minimale, regole AWS, generatore deterministico dei pattern da template, lettore del progetto kybes, gestore degli strumenti esterni con approvazione per strumento.

**Tech Stack:** Python ≥ 3.10 solo libreria standard (scripts e test `unittest`), Bash (installer), Terraform/OpenTofu HCL (template), TFLint + ruleset AWS, Checkov (o Trivy), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-20-kynfra-design.md` (approvato). Ogni task la implicita: leggerla prima di iniziare.

**Riferimento da portare:** dove un task dice "porta da kyfes", copiare il file di `kyfes/plugins/kyfes/…`, rinominare `kyfes`→`kynfra` (`.kyfes`→`.kynfra`, `KYFES_`→`KYNFRA_`, `tools/kyfes`→`tools/kynfra`) e togliere ciò che è specifico del frontend. Non reinventare ciò che kyfes ha già risolto (ricostruzione del file risultante, apply_patch di Codex, anti-loop dello stop gate, baseline di HEAD, percorsi case-insensitive).

## Global Constraints

- Script: solo libreria standard Python, compatibili con Python 3.10; avviati con `python3 -B`.
- Senza `.kynfra/config.json` ogni hook è un no-op (exit 0, nessun output).
- Le regole si applicano solo ai file sotto `infra_root` (`"infra"` se nel repo ci sono `.kybes/`, `.kyfes/` o `infra/`; altrimenti `"."`).
- Ambienti di default `dev`, `staging`, `prod`; regione di default `eu-south-1`; IaC default `terraform` (alternativa `opentofu`).
- Tag obbligatori in `default_tags`: `Project`, `Environment`, `Owner`, `CostCenter`, `ManagedBy` (= `"kynfra"`).
- Nomi delle risorse prefissati `<progetto>-<env>`; chiave di stato `<progetto>/<env>/<stack>.tfstate`; backend S3 con `encrypt = true` e `use_lockfile = true`.
- Layout ammesso sotto `infra_root`: `bootstrap/`, `modules/<pattern>/`, `envs/<env>/<stack>/`, `envs/shared/<stack>/`, `native/<pattern>/`.
- L'agente non esegue mai: `terraform|tofu apply|destroy|import|taint|untaint|plan|force-unlock|state <mutante>|workspace new|delete`, `init` senza `-backend=false`, CLI cloud mutanti (`aws` salvo `get-*|describe-*|list-*|sts get-caller-identity`; `az`, `gcloud`, `vercel`; `kubectl` salvo `get|describe|explain`; `helm` salvo `template|lint|show`).
- Nessuna soppressione inline (`checkov:skip`, `trivy:ignore`, `tflint-ignore`); eccezioni solo in `.kynfra/config.json` → `exceptions: [{rule, path, resource, reason, expires}]`.
- Strumenti esterni: download solo con `tools.py install <tool>` (uno per comando), da sorgenti ufficiali, checksum SHA256 verificato, in `.kynfra/bin/`, registrati in `.kynfra/tools.lock.json`.
- Comandi in kebab-case: `/kynfra:create-<pattern>-infra-aws` con pattern `network`, `spa`, `backend`, `elb`, `eks`, `ecr`, `secrets`.
- Moduli solo con risorse native dei provider; nessun modulo di terze parti.
- Testi rivolti all'utente (messaggi delle regole, skill, docs) in italiano; README in inglese; nomi di regole in kebab-case inglese come nella spec.
- Versioni di Terraform, provider (`aws`, `helm`, `random`), add-on EKS, TFLint, ruleset AWS di TFLint, Checkov, Trivy: definite una volta in `plugins/kynfra/templates/versions.json` (Task 14) e lette da template, `tools.py` e CI.

## Review Focus

1. **HCL con stringhe insidiose**: heredoc (`<<-EOT … EOT`) e stringhe con `{`, `}`, `#`, `//`, `${…}` non devono rompere la struttura dei blocchi né far nascere falsi commenti → test in Task 2 (`test_heredoc_and_braces_in_strings`).
2. **Varianti di comando per aggirare il divieto di apply**: `terraform -chdir=envs/prod apply`, `env TF_LOG=1 terraform apply`, `bash -c "tofu apply"`, `cd x && terraform apply -auto-approve`, `TF_CLI_ARGS_plan=…`, alias `tf apply` via `make`/script nel repo → test in Task 9 (`test_apply_variants_denied`).
3. **Repo esistente con violazioni pregresse**: un Edit non correlato su un file Terraform già non conforme non deve essere bloccato; deve esserlo una violazione nuova nello stesso file → test in Task 8 (`test_preexisting_violation_not_blocking`).
4. **Monorepo kybes/kyfes**: file fuori da `infra_root` (es. `services/x/handler.py`, `frontend/src/...`, `.github/workflows/x.yml`) non vengono mai valutati dalle regole IaC → test in Task 3 (`test_files_outside_infra_root_ignored`).
5. **File `.tf.json` e `*.auto.tfvars`**: le regole valgono anche nel formato JSON di Terraform e nei tfvars automatici, altrimenti basterebbe cambiare estensione per aggirarle → test in Task 2 (`test_tf_json_blocks`) e Task 4 (`test_secret_in_auto_tfvars`).

### Task 2: Parser HCL minimale (`hcl.py`)

**Files:**
- Create: `plugins/kynfra/scripts/hcl.py`
- Test: `tests/hooks/test_hcl.py`

**Interfaces:**
- Produces:
  ```python
  @dataclass
  class Block:
      type: str                 # "resource", "module", "provider", "terraform", "backend", "variable", "data", "locals", "output", annidati ("ingress", "default_tags", …)
      labels: List[str]         # es. ["aws_s3_bucket", "site"]
      line: int                 # riga di apertura (1-based)
      end_line: int
      attrs: Dict[str, Attr]    # attributi diretti
      blocks: List["Block"]     # blocchi annidati
      def get(self, name: str) -> Optional["Attr"]: ...
      def children(self, type: str) -> List["Block"]: ...
      def address(self) -> str: ...  # "aws_s3_bucket.site", "module.x", "provider.aws"
  @dataclass
  class Attr:
      name: str; line: int; raw: str     # espressione come testo, senza commento finale
      def literal(self) -> Optional[Union[str, bool, int, float, list, dict]]: ...  # None se non letterale
  def parse(text: str, filename: str = "main.tf") -> List[Block]       # .tf, .tfvars, .tf.json (dalla estensione)
  def parse_tfvars(text: str, filename: str) -> Dict[str, Attr]        # .tfvars e .tfvars.json
  def strip_comments(text: str) -> str                                 # sostituisce #, //, /* */ con spazi, rispetta stringhe e heredoc; preserva le righe
  ```
